1）预处理阶段：预处理器处理源文件中以 # 开头的预处理指令，生成 hello.i，预处理后仍然是高级语言。

解析要点

IPC（每周期指令数）越高越好，CPI（每指令周期数）越低越好，它们共同反映CPU的指令执行效率。
时钟频率(主频)是计算机系统中用于控制时序的基本参数，表示时钟信号在单位时间内的震荡次数。其单位是赫兹（Hz）。
时钟周期是时钟信号的震荡周期，时钟频率与时钟周期是反向关系：时钟周期 = 1 / 时钟频率
CPU 周期 (机器周期) 是指 CPU 完成一个基本操作所需要的时间单位。一个机器周期往往由多个时钟周期组成，一条指令的取出阶段需要一个 CPU 周期的时间。
CPI 是指执行一条指令所需要的平均时钟周期数。系统结构、指令集、计算机组织都会影响 CPI。
CPU 执行时间= =
CPU 性能取决于三个要素：主频、每条指令执行所用的时钟周期数、指令条数。

定量分析：CPU 执行时间 = (程序指令条数×每条指令时钟周期数 (CPI))/时钟频率。提高时钟频率显然可以缩短 CPU 执行时间；编译优化可能减少程序的指令数或优化指令结构；优化数据通路结构可能减少时钟周期，即提高时钟频率，故选 D。

重点

以下是对本章的一个知识梳理，对上述做题中写到的知识点不再重复（也可能重复）

冯·诺依曼机

  1. 冯诺依曼机共有五大部件：运算器、存储器、控制器、输入\输出设备
  2. 指令和数据以同等形式储存在存储器中，按地址寻址。
  3. 指令和数据在存储形式上没有区别，以二进制代码表示，计算机可以区分他们。
  4. 指令通常由操作码和地址码组成：操作码表示操作性质，地址码表示操作数在内存中的位置。
  5. 指令在存储器中按顺序存放。
  6. 早期冯诺依曼机是以运算器为中心，输入输出设备通过运算器与存储器传送数据。
  7. 冯诺依曼机属于指令流驱动控制，计算机通过执行程序来控制其操作，即按照指令序列逐条执行，完成各种运算，冯诺依曼机的基本工作方式是控制流驱动方式。
  8. CPU 可以判断指令周期的不同阶段：在取指阶段访问存储器取出的二进制代码是指令；在执行阶段访问存储器取出的是数据（操作数 ）。

计算机系统的工作原理

“存储程序”的基本思想是：将事先编制好的程序和原始数据送入主存储器后才能执行，一旦程序被启动执行，就无需操作人员的干预，计算机会自动逐条执行指令，直至程序执行结束。

三种编程语言

  • 机器语言：二进制代码语言，是机器唯一可以直接识别和执行的语言。
  • 汇编语言：用英文单词或其缩写代替二进制的指令代码，是为了增强机器语言的可读性和记忆性而设计的语言，经过汇编后才能被执行。
  • 高级语言：高级语言需要经过编译程序编译为汇编语言，再经过汇编器转为机器语言程序；或者直接由高级语言翻译为机器语言。如 C++、Python 等语言。

三种翻译程序

  • 汇编程序： 将汇编语言源程序翻译为机器语言目标程序
  • 编译程序：将高级语言源程序一次性翻译为汇编语言或机器语言目标程序。
  • 解释程序： 逐条翻译并立即执行高级语言源程序语句，不生成独立的目标程序

从源程序到可执行程序


1）预处理阶段：预处理器处理源文件中以 # 开头的预处理指令，生成 hello. i，预处理后仍然是高级语言。
2）编译阶段：编译器将 hello. i 翻译为汇编程序 hello. s，其中每条语句以文本形式描述一条低级机器指令。得到汇编语言
3）汇编阶段：汇编器将 hello. s 转为机器语言指令，生成可重定位目标文件 hello. o，该文件为二进制格式。得到机器语言
4）链接阶段：链接器将 hello. o 与标准库中所需函数进行链接，解析外部符号引用，最终生成完整的可执行文件 hello，并保存至磁盘。

指令集体系结构

指令集体系结构 (ISA)：软件与硬件之间的接口，定义了计算机可执行的所有指令的集合，包括指令、寄存器、寻址方式、存储器编址、异常和中断等所有程序员可见规范。ISA 被视为软件可见部分。

现代计算机组织结构

  • 现代计算机发展为以存储器为中心。
  • 运算器和控制器集成为中央处理器 CPU。
  • I/O 设备和主存储器直接进行数据交换。
  • 主存储器和 CPU 进行数据和指令交换。
  • 存储器分为主存和辅存（如硬盘）。

计算机的功能部件

中央处理器

现代计算机将运算器、控制器和各类寄存器高度集成，形成一块称为中央处理器（CPU）。
从功能结构上来看，CPU 主要包含两种基本部件：数据通路和控制器。

  • 数据通路主要包含算术逻辑部件（ALU）、通用寄存器等，其功能是用来执行算术和逻辑运算等操作，并实现数据在各部件之间的传输。
  • 控制器用来对指令进行译码，生成相应的控制信号，以控制数据通路进行正确的操作，保障指令有序执行。
    进一步细化，CPU 包含算数逻辑单元（ALU）、通用寄存器（GPRs）、标志寄存器（PSW）、控制器、指令寄存器 IR、程序计数器 PC、存储器地址寄存器 MAR 和存储器数据寄存器 MDR。

存储器

功能：计算机的存储部件，用来存放程序和数据。
组成：

  • 内存（包括主存和高速缓存）、外存（硬盘等辅助存储器）。
  • CPU 能直接访问主存储器，辅助存储器用于帮助主存记忆更多信息，辅助存储器的信息必须调入主存后才能被 CPU 访问。
  • 存储体由若干存储单元组成，存储单元由若干存储元件组成，每个存储元件储存一个二进制位。

MDR、MAR：

  • 地址存储器（MAR）存放访存地址，数据寄存器（MDR）用于暂存要从存储器中读写的数据，时序控制逻辑用于产生存储器操作所需要的各种时序信号。
  • MAR 用于寻址，其数位对应存储单元的个数。
  • MDR 的位数通常等于一次主存读写的数据宽度，常与存储字长相等。
  • MAR 反映存储单元的数量；MDR 反应存储单元的字长。

数据流向：

  • 取数据：数据的地址输入 MAR→取出 MAR 地址的数据存于 MDR 中→取出 MDR 中的数据。
  • 取指令：将 PC 内容输入 MAR 中→取出 MAR 地址的数据存于 MDR 中→取出 MDR 中的指令送到指令寄存器（IR）。

输入设备

功能：将程序和数据以机器所识别和接受的信息输入计算机

输出设备

功能：将计算机处理的结果以人们所能接受的形式或其它系统所需的格式输出。

运算器

功能：计算机的执行部件，用于进行算数运算和逻辑运算，对数据进行加工处理。
组成：

  • 若干通用寄存器，用于暂存操作数和中间结果。
  • 算数逻辑运算单元 ALU，累加器 ACC、乘商寄存器 MQ、操作数寄存器 X、变址寄存器 IX、基址寄存器 BR、程序状态寄存器 PSW。

控制器

功能：计算机的指挥中心，其指挥各部件自动协调的进行工作。
组成：
程序计数器 PC、指令寄存器 IR、控制单元 CU。
程序计数器 PC 用于存储当前即将执行的指令地址，并能够自动递增以形成下一条指令的地址。
指令寄存器 IR 保存当前执行的指令，指令内容源于主存的 MDR。指令中的操作码 OP（IR）传送到控制单元（CU），用于分析指令并产生相应的微操作信号；指令需要访存获取操作数时，指令中的地址吗 Ad (IR) 参与有效地址的计算，形成的有效地址再送入 MAR。
控制单元 CU 负责占领的解析，并根据解析结果生成相应的控制信号，控制数据的流动。控制器通过指令寄存器 IR、状态寄存器 PSW、时序电路的输入产生控制信息。

总线

CPU、主存和 I/O 接口通过总线互连。即地址、控制和数据三组总线。地址线用于指向读写操作的主存存储单元；控制线中包含读写信号线，用于指出数据是从 CPU 写入主存还是从主存读出到 CPU。

计算机软件和硬件的关系

软件按其功能可以分为系统软件和应用软件。

  • 系统软件：用于管理和控制计算机硬件和软件资源的软件，保证计算机系统高效、正确运行的基础软件，为其他软件提供了必要的环境。
  • 应用软件：是指用户为解决特定应用领域问题而开发的程序。

对于某一特定功能，既可采用硬件实现，又可通过软件实现；从用户视角看，在相同规范下，二者在逻辑功能上是等价的（也可说成等效）。

计算机的性能指标

主要性能指标

吞吐量和响应时间

吞吐量：指系统再单位时间内能够处理的请求数量。主要取决于主存的存储周期，是评价机器性能的综合参数。
响应时间：指用户向计算机发送一个请求，到系统对该请求做出响应并获得其所需结果的等待时间。包括 CPU 时间间 (程序实际运行时间) 与等待时间 (如磁盘访问、内存访问、I/O 操作等所花费的时间)。

主频和 CPU 时钟周期

主频：即 CPU 时钟频率，时钟周期的倒数。机器内部的主时钟的频率，主频越高完成指令的一个执行步骤所用的时间通常越短。通常以兆赫兹为单位。主频并不能直接代表运算速度。如10 Hz表示每秒 10 个时钟周期。
CPU 时钟周期：是 CPU 执行操作的最基本、最小的时间单位，每个动作至少需要一个时钟周期。

CPU 时钟周期=1/主频。

CPU 周期：又称机器周期，指 CPU 完成一个基本操作所需的时间单位。一个机器周期往往由多个时钟周期组成，一条指令的取出阶段需要一个 CPU 周期的时间。

CPI

执行一条指令所需要的平均时钟周期数。系统结构、指令集、计算机组织都会影响 CPI。
对于一条特定指令而言， CPI 指执行该条指令所需的时钟周期数，此时 CPI 是一个确定的值；对于一个程序或一台机器来说，其 CPI 指该程序或机器指令集中所有指令执行所需的平均时钟周期数，此时 CPI 是一个平均值。

字长

机器字长：进行一次整数运算所能处理的二进制数据的位数。
机器字长一般等于内部寄存器的位数和 ALU 运算数据的字长。
指令字长：一个指令字中包含的二进制代码位数。
存储字长：一个存储单元存储的二进制代码的位数。
指令字长一般取存储字长的整数倍。若指令字长等于存储字长的 n 倍，则取指周期就为 n 个存储周期，即需要 n 次访存。
