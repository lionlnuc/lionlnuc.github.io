复习

进位计数制及其相互转换

所有整数都可以用任何进制表示。
小数是离散的，并不是每个十进制小数都可以准确的用二进制表示，任意一个二进制小数都可以用十进制小数表示。
为便于区分，常在数字后添加后缀字母来标识进制：B 表示二进制数，O 表示八进制数，D 表示十进制数 (通常省略), H 表示十六进制数；此外，也常用前缀 0x 表示十六进制数。

任意进制转为十进制

采用按权展开相加法：将各位数码与其对应位权 (基数的幂次) 相乘，再求和。

十进制转为任意进制数

  1. 整数部分使用除基取余法：不断除以目标进制的基数，记录余数，直至商为 0; 最先得到的余数为最低位，最后得到的为最高位。
  2. 小数部分使用乘基取整法：不断乘以基数，记录整数部分，直至小数部分为 0 或达到所需精度。最先得到的整数为最高位，最后得到的为最低位。
    最终将两部分的转换结果拼接，即得到目标进制数。

二进制数转换为八进制数和十六进制数

对于一个既有整数部分又有小数部分的二进制数，转换时以小数点为界分别处理：整数部分， 从小数点向左，每 3 位 (八进制) 或每 4 位 (十六进制) 分为一组，若最左侧不足 3 位或 4 位， 则在高位补 0; 小数部分，从小数点向右，同样每 3 位或 4 位分为一组，若最右侧不足，则在低位补 0。分组完成后，将每组直接替换为对应的八进制或十六进制数码即可。

定点数的编码表示

定点数的小数点位置固定，分为定点小数（小数点位置在最高数位之前，即符号位之后）和定点整数（小数点位置在最低数位之后）。
通常用定点补码整数表示整数，用定点原码小数表示浮点数的尾数部分，用移码表示浮点数的阶码部分。

原码

机器数的最高位表示数的符号：0 表示正数，1 表示负数。正负数的编码表示仅符号位不同，数值部分完全相同。
真值零的原码表示有正零和负零两种形式。
优点：①与真值的对应关系简单、直观，转换简便；②用原码实现乘除运算比较简便。
缺点：①零的表示不唯一，存在 ± 0 两种编码；②用原码实现加减运算比较复杂。

补码

正数的补码和原码一样；负数的补码等于模与该负数绝对值之差。
零的补码是唯一的：，小数补码比原码多表示一个小数“-1”，整数补码比原码多表示一个整数“”。负数的补码到真值，以及从真值到补码，都是符号位不变，其余按位取反再加一。
补码可将减法操作转变为等价的加法操作，使 ALU 中无需集成减法器。
几个特殊的补码（n+1 位）：

  1. (全 0), 零的补码表示是唯一的。
  2. (全 1)。
  3. 最大正整数： (符号位为 0, 数值位全 1)。
  4. 最小负整数： (符号位为 1, 数值位全 0)。

反码

正数的反码和原码一样；负数采用“符号位不变，数值位按位取反”。
反码表示存在明显不足：①零的表示不唯一 (存在±0 两种编码);②表示范围与相同字长 的原码相同，比补码少一个最小负数 ()。因此，反码在计算机中极少使用。

移码

在真值 x 上加一个常数（偏置值），其中机器字长 n+1 位移码的偏置值= ，，相当于数轴整体右移 。
形式上等于将补码的符号位取反，数字上移码＝真值+偏置值。移码保持了数据原有的大小顺序，移码的值越大，其对应的真值也就越大，对比两个移码大小很方便。
n+1 位移码的偏置值取 时，用来表示浮点数的指数部分（阶码），只能表示整数。
移码中零的表示唯一（）。
当偏置值为 时，真值的移码和补码仅差一个符号位。

①正数的原码、反码、补码相同；移码则不同。
②原码与反码在数轴上关于原点对称，二者都存在+0 与-0。
③补码与移码的表示不对称，零的表示唯一，且比原码和反码多表示一个负数 ()。
④原码可直观的比较大小 (因数值部分即绝对值), 而负数的补码和反码不能像原码那样直观判断。不过，在同为负数的前提下，补码或反码的数值部分越大，其真值也越大。

原码、反码、补码、移码的表示范围（字长为 n+1）：

原码
（反码）		纯小数：纯整数：表示范围关于原点对称
补码纯小数：纯整数：为了消除减法
移码移码全 0，真值最小 移码全 1，对应最大值 可以直接反映真值大小

转换

原码→反码：若符号位为 0 则不变，若符号位为 1 则符号位不变数值位按位取反。
原码→补码：若符号位为 0 则不变，若符号位为 1 则符号位不变，数值位按位取反，变为反码，末位加一得到补码。
补码→原码：负数：符号位不变，数值位取反，再在末尾加 1。

整数的表示和运算

无符号整数的表示

编码的全部二进制位均为数值为而没有符号位时，该编码表示的就是无符号整数，也直接称为无符号数。
默认数的符号为正。省略了一位符号位，字长相同时，无符号数能表示的最大整数比有符号整数能表示的大。
例如，8 位无符号整数的最小值为 0000 0000 (0), 最大值为 1111 1111 ( -1=255), 表示范围为 0～255; 而 8 位有符号整数 (补码表示) 的最小值为 1000 0000 (-2?=-128), 最大值为 0111 1111 ( -1=127), 表示范围为-128～127。

有符号整数的表示

将符号用二进制表示，0 的补码表示唯一。
与原码和移码相比，补码运算规则比较简单，且符号位可以和数值未一起参与运算。
与原码和反码相比，补码比原码和反码多表示一个最小负数。

C 语言中的整数类型及类型转换

  • 短整型：short (或 short int), 通常为 16 位。
  • 整型：int, 通常为 32 位。
  • 长整型：long (或 long int), 在 32 位系统中为 32 位，在 64 位系统中通常为 64 位。 在上述类型前添加 unsigned 关键字，可定义对应的无符号类型 (如 unsigned int、unsigned short 等)。若未显式指定 signed 或 unsigned, 则默认为有符号类型。
  • 字符型 (char, 通常为 8 位) 是一种特殊的整型，通常可按无符号整数解释。
    在现代系统中，所有有符号整型均以补码形式存储。

转换规则：
(1) 长类型转换为短类型：位截断 转换规则：保留低位，丢弃高位。
(2) 相同字长的转换：仅改变解释方式 转换规则：二进制位模式保持不变，仅重新解释其含义。
(3) 短类型转换为长类型：位扩展 转换规则：若源数据为有符号数，则执行符号扩展；若源数据为无符号数，则执行零扩展。

移位运算

对于任意二进制整数，左移一位，若未发生溢出，相当于乘以 2 (类似于十进制数左移一位相当于乘以 10); 右移一位，若忽略因移出而舍去的末位尾数，相当于除以 2。
移位运算可以分为逻辑移位、算术移位和循环移位。

逻辑移位

针对无符号数。符号位参与（所有位同等处理），左移右移都补 0。

算术移位

针对有符号数，移位过程中，需要考虑符号位，将操作数视为有符号数。
对于正数，原码=补码=反码，不论左移还是右移都补 0。
对于负数，原码左移和右移都补 0；反码左移和右移都补 1；补码由于左边和反码相同，右边和原码相同，所以补码左移补 0，右移补 1。

码制 空位填补 丢位情况
正数 原码=补码=反码 0 最高位丢 1，则结果错误
最低位丢 1，则精度缺失
负数 原码 0 最高位丢 1，则结果错误
最低位丢 1，则精度缺失
补码 左移添 0 最高位丢 0，则结果出错
右移添 1 最低位丢 1，则精度缺失
反码 1 最高位丢 0，则结果错误
最低位丢 0，则精度缺失

在未出现因丢位产生结果出错或精度缺失的情况下：
左移：乘
右移：除以
其中 n 为移位次数。

另一种算数移位

符号位也参与移位，仅针对补码
左移：高位移除，低位补 0；移动前后若符号位发生变化，则发生溢出。
右移：低位移除，高位填补符号。

循环移位

串行进位加法器

将 n 个全加器级联可构成 n 位串行进位加法器。
①把两个操作数各放在一个移位寄存器中，移位寄存器从低位到高位提供操作数进行相加。
②每步产生一位和，串行地送入寄存器；保存产生的进位信号只需要一个触发器。
③每完成一步，用新进位置覆盖旧进位。
优点：器件少，成本低。
缺点：运算时间由进位信号传递时间决定，位数多时运算速度慢。

并行进位加法器

将 n 个全加器串接起来，每一级的进位输出直接作为下一级的进位输入。这种“一级一级传递进位”的机制意味着每一位求和及进位的产生，都直接依赖于前一级进位结果。进位信息串行产生。
它主要用于解决多位二进制加法中，低位向高位的进位传递所导致的延迟问题。

带标志加法器

对于 n 位加法器来说，除了得到运算结果外，还要关注加法运算过程中是否发生了溢出、结果的正负性、结果是否为零等，这些信息对于程序的执行控制非常关键。
（1）零标志 ZF
①表示结果是否为 0。ZF = 1 表示运算结果为 0，ZF = 0 表示结果非 0。
②不管对于无符号数还是带符号整数运算，ZF 都有意义。常用于条件判断和控制流程中。
③硬件计算方法：两个数的运算结果为 n 位，只有 n 位全为 0 时，ZF = 1。
对于逻辑运算指令，通常只有零标志 ZF 才有意义。可以通过 ZF 确定与或非等操作的结果是否为 0。
（2）溢出标志 OF
①表示带符号整数运算时发生溢出。OF=1 时，说明发生了溢出。
②对于无符号运算，OF 没有意义。
③硬件计算方法：OF=最高位（符号位）产生的进位 次高位（数值部分的最高位）产生的进位。
对于移位指令，因为左移一位，数值扩大一倍，所以左移指令的结果可能会发生溢出。因此，有些机器的左移指令会生成 OF 标志。
（3）符号标志 SF
①表示结果的符号，即 F 的最高位。SF=0 为正数，SF=1 为负数。
②对于无符号数的加减运算，SF 没有意义。
③硬件计算方法：SF=最高位的本位和。
有的机器在算数左移时将操作数的最高位移入进位标志，通过判断符号标志和进位标志是否相等来判断是否发生了溢出。
（4）进/借位标志 CF
①表示无符号整数运算时的进位/借位，同时作为无符号数运算是否发生溢出的标志。
加法时，CF=1 表示有结果溢出，CF 等于进位输出 。
减法时，CF=1 表示有借位，CF 等于进位输出 取反。
②对于有符号补码运算，进位标志 CF 不用于判断溢出，无意义；有符号数溢出靠 OF 判断。
③硬件计算方法：CF=Sub （Sub=1 表示减法；Sub=0 表示加法。 表示最高位产生的进位）

算术逻辑单元（ALU）

ALU 是一种功能较强的组合逻辑电路，能够执行多种算术与逻辑运算。其中，加法和减法由带标志加法器直接完成；乘法和除法则通常通过 ALU 配合控制逻辑，以多次加减和移位的方式迭代实现。此外，ALU 还能执行与、或、非等基本逻辑运算。

定点数加/减运算

实现方法

加法：无符号整数加法，从最低位开始按位相加并且往更高位产生进位信息。
减法：被减数不变，减数变为其负数的补码，减法变加法。按加法规则运算。

原码加减运算

在原码加减运算中，首先需要判断两个操作数的符号，并分开处理符号位与数值位。对于加法运算，遵循“同号求和、异号求差”的规则；对于减法运算，则是“同号求差，异号求和”。
在求和时，直接对数值为进行相加，符号位则直接采用被加数的符号来确定结果。若最高位数值位产生进位，则会导致结果溢出。
在求差时，需要将减数的数值为转换为补码，然后再与被减数数值位相加。若最高位数值位产生进位，则表明所得数值位时正确的，结果的符号取决于被减数的符号。若最高位数值位未产生进位，则意味着结果为负数，此时需要将结果的数值位取反加一，符号位则需取被减数的符号位的反。

溢出

数据的值超出了有效的表示范围。本质：数据位有限。
上溢（正溢出）：大于机器所能表示的最大正数。
下溢（负溢出）：小于机器所能表示的最小负数。
定点小数：①两个定点小数相加大于/等于 1→上溢；②两个定点小数相加小于-1→下溢。
